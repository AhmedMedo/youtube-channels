# youtube-channels

Private production repo for Ahmed's faceless YouTube channels.

| Folder | What |
|---|---|
| `shared/` | Code used by every channel (procedural music + SFX in `audio.py`) |
| `numbers-in-motion/` | Data-viz channel: renderer, data, brand assets, `PLAYBOOK.md` for Team 1 |
| `sleep-channel/` | Sleep / relaxing music channel (planned) — `PLAYBOOK.md` for Team 2 |

Each scheduled Claude "team" starts by reading its folder's `PLAYBOOK.md`.
